How this prediction works

1. Start with real resultsThe current ESPN table sets the baseline. Completed matches are never overridden by predictions. The fixture archive is used only when required, with its limitations labelled.
2. Rate every clubRecent results, goals scored and conceded, home advantage and an Elo-style strength rating influence the goals predicted in each unplayed match.
3. Simulate thousands of futuresEach Monte Carlo run samples new scores for every unplayed fixture, adds them to the real current standings, and counts where all clubs finish. The model reruns when completed results change.

This is a learning model, not a betting forecast. Rescheduled games, points deductions, incomplete feeds and changing fixtures can affect the projected table. Forecasts are recalculated rather than stored as immutable weekly predictions.
